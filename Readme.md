# Hybrid ML/DL Stock Market Prediction Engine FeatureLevelFusion.py

## Overview
This project implements a state-of-the-art Multi-Input Branch Architecture to predict stock market movements. Instead of relying on a single algorithm, this system utilizes a hybrid ensemble approach. It isolates different types of financial data (sequential price action, point-in-time technicals, market sentiment, and statistical forecasts) into specialized models before merging their learned features for a final predictive classification.

## Architecture Breakdown

The system is built on four core components:

### 1. Branch A: The Sequence Reader (`xLSTM`)
* **Input:** Historical OHLCV (Open, High, Low, Close, Volume) time-series data.
* **Function:** Utilizes an Extended Long Short-Term Memory (xLSTM) network to process sequential data and extract long-term structural price trends without being distracted by daily noise.
* **Output:** A compressed mathematical vector representing the historical trend.

### 2. Branch B: The Snapshot Reader (`Dense Neural Network` + `SARIMA`)
* **Input:** Technical Indicators (RSI, MACD, etc.), NLP Sentiment Scores, and a $t+1$ statistical forecast generated by a SARIMA model.
* **Function:** Uses Fully Connected (Dense) layers to process static, point-in-time tabular data. The SARIMA model acts as an advanced feature generator, providing a baseline statistical forecast that the Dense layers weigh against current momentum and sentiment.
* **Output:** A vector representing the current market snapshot.

### 3. The Merge Node (`Concatenation`)
* **Function:** Glues the sequential trend vector from Branch A and the snapshot vector from Branch B into a unified array, creating a holistic view of both past trends and present conditions.

### 4. The Decision Head (`Support Vector Machine`)
* **Input:** The unified array from the Merge Node.
* **Function:** Replaces the traditional neural network output layer. The SVM acts as a margin-based classifier to draw strict, non-linear boundaries between "Buy", "Hold", and "Sell" signals based on the deep features extracted by the preceding branches.

## Data Flow
1. **Raw OHLCV** ➡️ `xLSTM` (Branch A)
2. **Raw Close Price** ➡️ `SARIMA` ➡️ Forecast Feature
3. **Forecast + Technicals + Sentiment** ➡️ `Dense Layers` (Branch B)
4. **Branch A Output + Branch B Output** ➡️ `Merge Node`
5. **Merged Feature Vector** ➡️ `SVM` ➡️ **Final Market Prediction**

## Prerequisites and Setup
To run this architecture, you will need a standard Machine Learning Python environment. 

### Core Dependencies:
* `tensorflow` or `keras` (For the multi-input neural network and xLSTM)
* `scikit-learn` (For the SVM classifier and data scaling)
* `statsmodels` (For the SARIMA implementation)
* `pandas` & `numpy` (For strict time-series alignment and feature engineering)

## Important Considerations: Data Alignment
When fusing time-series data with point-in-time sentiment and statistical forecasts, **lookahead bias** is the primary risk. Ensure that your pandas DataFrames strictly shift features so the model only ever predicts $t+1$ using data strictly available at or before $t$.
